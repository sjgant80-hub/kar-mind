# Security

kar-mind is supplied by AI Native Solutions. Report a security issue through the supplier's site,
https://www.ai-nativesolutions.com, rather than in a public issue.

A fix ships as a commit to this repository, through the same gates as any other change: the whole test suite on
Node 18, 20 and 22, and the witness mutation gate (pinned v0.6, no cap, nothing baselined) on every kernel, on
GitHub's runner, on every push. What the code sends off the machine, what it stores and what it never holds is set
out on the live page, under "Security and data protection": https://sjgant80-hub.github.io/kar-mind/#business
