kar-mind

A persistent, autonomous cognitive stack that composes verified memory organs into one runnable system — and structurally cannot publish or spend.

kar-mind wires small, independently-gated memory organs into one mind. It perceives a fact, cross-checks it against independent sources, consolidates it into meaning, generates new facts and loops them back, and births new domains — through real organs, with every state change read from each organ's own count. Nothing here uses an LLM as a judge; every check is deterministic and re-runnable.

The organs

  • crystal — exact facts, no drift; a read never blends one source's value into another's.
  • octa — verify: cross-checks 3+ independent sources per field, refuses a panel of duplicates.
  • strand — the movement law: recall score, then promote / hold / decay / expire, then the shelf transition.
  • dodeca — meaning: cosine-embedding retrieval.
  • icosa — generate: a dream cycle infers new facts from repeated patterns and loops the best back.
  • tetra — birth: bounded new-domain detection (novelty threshold + hard capacity cap).

It survives a restart

Cognition is event-sourced: every state-changing verb records its cause. The log is sealed to disk with real gzip and a receipt hash over every field (tamper-refused on load), and on boot the organs replay it and reach identical counts — a write-ahead-log persistence architecture. A brand-new process boots from the durable file alone and comes back whole.

It runs its own loop

From one call, the run-loop pulls its own stimuli and drives the full cascade over and over, moving real organ state with no caller per step — governed by a safety cap, stopping on dead air rather than spinning, and persisting itself each beat.

The safety wall. The autonomous loop can perceive, verify, consolidate, dream, and route — all cognition, all reversible, all inside the mind's own walled memory. It cannot publish or spend: the loop has no path to any irreversible outside-world action, by construction. The export door stays doubly gated by a consent id and a path wall, and a test proves a full autonomous run writes no file.

Run it

git clone https://github.com/sjgant80-hub/kar-mind.git
git clone https://github.com/sjgant80-hub/fall-remember.git
git clone https://github.com/sjgant80-hub/the-dreamer.git
git clone https://github.com/sjgant80-hub/fallforgecell.git

cd kar-mind
node mind-autonomous-demo.mjs   # boot, run the loop, persist, restart from disk
node --test                    # the full gate suite

Requires Node 18+ (standard CompressionStream gzip and the built-in node --test runner). No dependencies.
